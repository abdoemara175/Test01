# Pixel Community 🚀

[![Pixel Community CI Pipeline](https://github.com/abdoemara175/Pixel-Community/actions/workflows/ci.yml/badge.svg)](https://github.com/abdoemara175/Pixel-Community/actions/workflows/ci.yml)
[![Deploy Pixel Community to GitHub Pages](https://github.com/abdoemara175/Pixel-Community/actions/workflows/deploy.yml/badge.svg)](https://github.com/abdoemara175/Pixel-Community/actions/workflows/deploy.yml)

المنصة التفاعلية الرسمية لمجتمع **Pixel** المخصصة للمصممين والمطورين لمشاركة الأفكار، والتصاميم، والمشاركة في الفعاليات والتحديات الأسبوعية.

---

## 🎨 المميزات الرئيسية (Key Features)

- **منتدى النقاشات (Discussions Feed):** تصفح المنشورات بحسب التخصصات (UI/UX، Frontend، طلب نقد، أدوات وتقنيات) مع إمكانية التصفية والبحث الفوري.
- **معرض أعمال المبدعين (Community Showcase):** استعراض تصاميم ومشاريع الأعضاء المميزة وحصد الإعجابات.
- **فعاليات وورش عمل (Events & Workshops):** متابعة مواعيد اللقاءات المباشرة وحجز المقاعد.
- **لوحة المتصدرين (Leaderboard):** تكريم أكثر الأعضاء مساهمة وتفاعلاً داخل المجتمع.
- **تصميم عصري (Dark/Purple Theme):** واجهة مستخدم نيون زجاجية (Glassmorphism) تتوافق مع أعلى معايير الجمالية وإمكانية الوصول.

---

## 🛠️ التكنولوجيات المستخدمة (Tech Stack)

- **Core**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Typography & Icons**: Google Fonts (Readex Pro / Outfit), FontAwesome 6
- **CI/CD**: GitHub Actions (`.github/workflows/ci.yml` & `.github/workflows/deploy.yml`)
- **Hosting**: GitHub Pages

---

## 🚦 GitHub Developer Workflow & Contributions

نتبع في هذا المشروع **Conventional Commits** لتوثيق التعديلات بدقة:

- `feat(community):` إضافة ميزات جديدة بالواجهة أو المنصة.
- `fix(ui):` إصلاح التنسيقات أو الأخطاء البرمجية.
- `docs(readme):` تحديث الوثائق والتعليمات.
- `style(css):` تحسين الهوية البصرية والألوان.
- `ci(actions):` تحديث سير عمل GitHub Actions.

## 💻 التشغيل المحلي (Local Setup)

1. **استنساخ المستودع (Clone Repo):**
   ```bash
   git clone https://github.com/abdoemara175/Pixel-Community.git
   cd Pixel-Community
   ```

2. **تشغيل الموقع:**
   قم بفتح ملف `index.html` مباشرة في المتصفح أو استخدم إضافة `Live Server`.
